## 2. One focused report, saved in the personal folder

First ensure `ros_message_sample.py` is copied into `~/fahad/tools/`.
In terminal C, paste the following block once. Expected duration is a few minutes;
each query has an outer deadline, and absent transforms are useful findings.
It does not change parameters, publish TF, command movement or start sensors.

```bash
source ~/wheeltec_robot/devel/setup.bash
mkdir -p ~/fahad/reports
(
set -x
date -Is
timeout -k 2s 15s rosnode list
timeout -k 2s 15s rostopic info /camera/rgb/image_raw
timeout -k 2s 15s rostopic info /scan
timeout -k 2s 15s rostopic info /tf
timeout -k 2s 15s rostopic info /tf_static
timeout -k 2s 25s python -u ~/fahad/tools/ros_message_sample.py /camera/rgb/image_raw sensor_msgs/Image
timeout -k 2s 25s python -u ~/fahad/tools/ros_message_sample.py /camera/rgb/camera_info sensor_msgs/CameraInfo
timeout -k 2s 25s python -u ~/fahad/tools/ros_message_sample.py /scan sensor_msgs/LaserScan
timeout -k 2s 25s python -u ~/fahad/tools/ros_message_sample.py /darknet_ros/bounding_boxes darknet_ros_msgs/BoundingBoxes
timeout -k 2s 25s python -u ~/fahad/tools/ros_message_sample.py /tf_static tf2_msgs/TFMessage
timeout -k 2s 15s rostopic hz /scan
timeout -k 2s 15s rosrun tf tf_echo camera_rgb_optical_frame laser
) 2>&1 | tee ~/fahad/reports/fusion_check_$(date +%Y%m%d_%H%M%S).txt
```

`set -x` labels the commands inside the report; it is confined to the subshell.
Read all of the resulting file, not just the last line. Continuous `hz` and
`tf_echo` queries deliberately end at their deadline; this is not a sensor crash.
The helper reports no message after a ten-second subscription wait; outer timeout
can also terminate slow initialization. Neither alone proves a broken sensor.
If a message class/script cannot be found, save the error; do not reinstall ROS.

Expected names are `camera_rgb_optical_frame` and `laser`, based on prior reports.
If live frame names differ, the TF query will need those actual names after
review. Do not rename sensor frames or publish an identity transform to force a
connection. Sequential samples give interface/metadata evidence, not synchronized
fusion data, exact exposure matching, inference FPS or association accuracy.

Send the complete `fusion_check_...txt` file first. Optionally include a current
photo of the box/robot arrangement or a readable sensor label, without handling
the powered scanner. A new annotation exercise is not needed.
